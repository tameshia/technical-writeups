## Topics to Study

- How Splunk ingests, indexes, and searches log data
- How events appear in search results
- Common event fields, including timestamps, hosts, sources, and sourcetypes
- How to expand an event and examine its contents
- How searches can help reveal repeated activity or unusual patterns

## Why Log Analysis Matters

Logs can provide evidence about user authentication, system behavior, and network or application activity. Reviewing them helps administrators and security analysts investigate issues and identify patterns that deserve further attention.

Splunk is one platform that can be used to search and analyze machine-generated data. Understanding event fields and search results is a useful starting point before working with more advanced detection and correlation tasks.
